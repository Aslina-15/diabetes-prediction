# Diabetes Prediction System

A Streamlit web app that predicts diabetes type from health inputs using machine learning
(Random Forest, Gradient Boosting, Logistic Regression), with login, doctor booking and a health chatbot.

**Live demo:** https://diabetes-prediction-aslee.streamlit.app

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Tech
Python, Streamlit, pandas, NumPy, scikit-learn, imbalanced-learn
